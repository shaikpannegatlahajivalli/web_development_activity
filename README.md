## Project 1 – FITZONE: Gym Website

### Description

FITZONE is a gym and fitness website developed using HTML5 and CSS3. It presents workout programmes, trainer categories, membership plans, facilities, a weekly class schedule, and a registration form.

### Objectives

- Create a multi-section webpage using semantic HTML.
- Apply CSS for colours, spacing, alignment, grid layout, and hover effects.
- Add navigation links between sections.
- Present gym programmes, trainers, membership plans, and class information.
- Practise creating and styling a basic HTML form.

### Features

- FITZONE branding and navigation links.
- Hero section with "BUILD YOUR BEST BODY".
- Workout programmes: Strength Training, Cardio Fitness, and Yoga & Flexibility.
- Trainer categories: Strength Coach, Cardio Coach, and Yoga Instructor.
- Membership plans:
  - Basic – 999/- per month
  - Standard – 1,499/- per month
  - Premium – 2,499/- per month
- Facilities: Modern Equipment, Locker Rooms, and Personal Training.
- Class schedule: Monday – Yoga, Wednesday – Cardio, Friday – Strength.
- Registration form with name, email, phone, text, and membership fields.
- CSS Grid, hover transitions, and a media query.

### Technologies

- HTML5
- CSS3 (Flexbox, CSS Grid, transitions, media query)

### Output Screenshot

![FITZONE Output](screenshots/fitzone.png)

**Implementation notes:** The project has no JavaScript or backend connection. The registration form does not store or transmit data. The Join Now button has no navigation handler. The three-column card grid is not changed for narrow screens.

### Description

The City Hospital Website is an informational webpage developed using HTML5 and CSS3. It presents hospital information, medical departments, doctors, facilities, visiting hours, an appointment form, and emergency contact details.

### Objectives

- Present the hospital name and welcome message.
- Display medical departments and doctors.
- List facilities and visiting hours.
- Provide a basic appointment form.
- Display emergency contact information.
- Add internal navigation and responsive navigation.

### Features

- Sky-blue header with City Hospital branding.
- Welcome section.
- Departments: Cardiology, Neurology, Dentistry, and Pediatrics.
- Doctors: Dr. Ravi (Cardiologist) and Dr. Priya (Dentist).
- Facilities: ICU, Pharmacy, Laboratory, and Ambulance.
- Visiting hours: 10 AM to 5 PM.
- Appointment form with Name, Email, and Date fields.
- Emergency contacts: Ambulance 108 and Phone 9876543210.
- Sky-blue footer.
- Navigation links stack vertically at screen widths of 600 pixels or less.

### Technologies

- HTML5
- CSS3

**Implementation notes:** The appointment form is front-end only. It is not connected to a booking system and does not save appointment data. No JavaScript, database, backend framework, or external image library is used.

## How to Run

These are static HTML/CSS projects and do not require a backend server.

1. Download the repository using Code → Download ZIP, or clone it:

   ```bash
   git clone <your-repository-url>
   ```

2. Extract the ZIP file.
3. Open the project folder.
4. Open the relevant HTML file in a web browser.

Project-specific notes:

- FITZONE: Open its HTML file. The stylesheet is named `task 1.css`. The HTML filename is not specified in the report.
- City Hospital: Open `index.html` and keep `hospi.css` in the same folder.
- University Information Website: Open `collage.html` and keep `collage.css` and `imaaa.jpg.jpeg` in the expected locations.
